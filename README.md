# LiDAR Capture

Мини-приложение для iPhone с LiDAR: записывает **сырые данные сканирования**
(кадры камеры, глубину LiDAR, достоверность, позиции камеры) и показывает
**сетку покрытия прямо во время съёмки**.

## Сборка без Mac (бесплатно)
1. Создать репозиторий на GitHub (публичный — минуты macOS бесплатные) и залить туда эту папку.
2. Вкладка **Actions** → workflow «Build unsigned IPA» запустится сам при push (или вручную «Run workflow»).
3. Через ~10 минут открыть завершённый запуск → внизу **Artifacts** → скачать `LidarCapture-ipa` (внутри `LidarCapture.ipa`).

## Установка на iPhone с Windows (бесплатный Apple ID)
1. Установить **iTunes** (версию с сайта Apple, не из Microsoft Store) и **Sideloadly** (sideloadly.io).
2. Подключить iPhone по USB, нажать «Доверять этому компьютеру».
3. В Sideloadly: перетащить `LidarCapture.ipa`, ввести свой Apple ID → Start.
4. На iPhone:
   - Настройки → Конфиденциальность и безопасность → **Режим разработчика** → вкл. (перезагрузка);
   - Настройки → Основные → **VPN и управление устройством** → свой Apple ID → Доверять.
5. Приложение работает **7 дней**, потом повторить шаг 3 (пересобирать не нужно).

## Как снимать
- Зелёная/цветная сетка поверх камеры = уже отсканировано. Где сетки нет — доснять.
- «Запись» → медленно обойти комнату (3 наклона: вниз / прямо / вверх) → «Стоп» → «Экспорт» (zip в Файлы/AirDrop).
- Сессии также видны в приложении «Файлы» → На iPhone → LiDAR Capture.

## Формат записи (`scan_YYYYMMDD_HHMMSS/`)
- `meta.json` — описание формата.
- `poses.jsonl` — одна строка JSON на кадр:
  `i` индекс, `t` время (с), `w,h` размер RGB, `fx,fy,cx,cy` интринсики для RGB,
  `dw,dh` размер карты глубины (обычно 256×192), `T` — 4×4 camera→world, column-major
  (система ARKit: x вправо, y вверх, z назад; камера смотрит в −z).
- `frames/NNNNNN.jpg` — RGB в исходной ориентации сенсора (landscape), соответствует интринсикам.
- `frames/NNNNNN.depth` — uint16 little-endian, миллиметры, `dw×dh`, 0 = нет данных.
- `frames/NNNNNN.conf` — uint8 на пиксель глубины: 0 низкая, 1 средняя, 2 высокая достоверность.
- Интринсики глубины = интринсики RGB × (dw / w).
- Частота: 5 кадров/с, кадры с плохим трекингом пропускаются.
